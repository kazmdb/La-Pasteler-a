🚀 Inicializar Pedidos

Utiliza esta herramienta para inicializar la colección de pedidos en Firebase con datos de ejemplo.

📋 Estructura de Pedidos

  • ID único para cada pedido
  • Información del cliente (nombre, teléfono, email)
  • Estado del pedido (pendiente, en_preparacion, entregado, cancelado)
  • Lista de productos con cantidades y precios
  • Método de pago y dirección de entrega
  • Notas adicionales del cliente
